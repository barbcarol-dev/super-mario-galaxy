# Super Mario Galaxy: O Filme - Landing Page

Landing page temática e interativa desenvolvida para a divulgação conceitual do filme **Super Mario Galaxy**. O projeto conta com design estilizado no universo espacial da franquia, galeria de personagens, exibição de trailers, animações de navegação e um contador regressivo em tempo real para a data de estreia.

---

## Funcionalidades

- **Interface Temática Espacial:** Visual moderno utilizando efeitos visuais em CSS3 e fundo estelar estilizado.
- **Menu de Navegação Dinâmico:** Links para rolagem suave entre as seções (Personagens, Trailers e Estreia).
- **Galeria do Elenco:** Apresentação visual dos personagens principais do filme.
- **Central de Mídia:** Seção dedicada para exibição dos trailers oficiais.
- **Contador Regressivo (Countdown):** Temporizador contínuo em JavaScript que calcula o tempo restante até a estreia.
- **Animações de Scroll:** Efeitos visuais ativados durante a navegação do usuário.

---

## Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da página.
- **CSS3:** Estilização personalizada, posicionamento em Flexbox/Grid, efeitos visuais e responsividade.
- **JavaScript (ES6):** Lógica para manipulação do DOM, contador regressivo e controle de animações de rolagem.

## Como Executar o Projeto

### Pré-requisitos

Não é necessária a instalação de dependências de backend ou gerenciadores de pacote. Apenas um navegador web atualizado.

### Instruções

1. Clone este repositório:
   ```bash
   git clone https://github.com/barbcarol-dev/super-mario-galaxy.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd super-mario-galaxy
   ```

3. Abra a aplicação:
   - Dê um duplo clique no arquivo `index.html` para abrir diretamente no seu navegador, ou utilize a extensão **Live Server** no VS Code.
